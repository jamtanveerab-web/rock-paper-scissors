# ✊ Rock Paper Scissors Game

A classic Rock Paper Scissors game built with HTML, CSS, and JavaScript. Play against the computer with real-time score tracking.

## 🎮 How to Play

- Click on **Rock**, **Paper**, or **Scissors**
- Computer randomly selects its choice
- Winner is decided by rules:
  - Rock beats Scissors
  - Scissors beats Paper
  - Paper beats Rock
- Score updates automatically after each round

## ✨ Features

- Clean and simple UI
- Real-time score display (You vs Computer)
- Shows both player and computer choices
- Reset button to restart game
- Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📚 What I Learned

- JavaScript functions and event listeners
- Random number generation
- Conditional logic (if-else)
- Dynamic DOM manipulation
- Score tracking across rounds

## 🚀 How to Run

1. Clone this repository
2. Open `index.html` in any browser
3. Start playing!
